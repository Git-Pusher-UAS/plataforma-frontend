# Seguridad

## Cómo reportar una vulnerabilidad

No abras un tema público. Usa el reporte privado de vulnerabilidades de GitHub (pestaña *Security* → *Report a vulnerability*) o escribe directamente a la persona responsable de seguridad del equipo.

Incluye: qué encontraste, pasos para reproducirlo y qué impacto crees que tiene. No incluyas datos personales reales.

## Qué esperar

Se confirma la recepción en un plazo breve, se evalúa el impacto y se informa cuando haya una corrección.

## Alcance

Este repositorio es un prototipo y usa exclusivamente datos ficticios. Aun así, se reportan los hallazgos como si fueran reales, porque el diseño está pensado para proteger información sensible.
